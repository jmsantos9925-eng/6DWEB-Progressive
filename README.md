# The Candy Store

A progressive project for 6DWEB.

## Module 1

The first three commits contain the original four PHP pages, stylesheet, and images. The complete original version is available at commit `4039a66`.

## Module 2

The same pages now use control structures and shared files.

| Page | Added concepts |
| --- | --- |
| Home | switch, if/else, foreach |
| Candy | foreach, if/elseif/else, stock total |
| Favorites | for, foreach, ternary, empty list condition |
| Cart | while, logical operators, stock conditions |
| Promos | do/while, if/else, match |

Each page uses require for the header and include for the footer. The original candy design and images are retained. The subtotal calculation and broken title tag are also corrected.

## Run

1. Download the repository as a ZIP and extract it.
2. Copy the project folder into `C:\xampp\htdocs` and rename the folder `Santos`.
3. Start Apache in XAMPP.
4. Open `http://localhost/Santos/` in Chrome.
5. Use the navigation to view all five pages.

PHP 8 or newer is required for match. Values are set in the PHP files, like the original activity. No database is needed.

## Submission

Set Chrome zoom to 100% and resize the browser to 3/4 of the screen. Use GoFullPage to capture the output pages. Upload the screenshots to Canvas and put the repository link in the assignment comment section.
